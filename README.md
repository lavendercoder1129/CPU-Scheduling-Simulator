# CPU Scheduling Algorithm Simulator

C++ based CPU scheduling algorithm simulator implementing various Operating Systems Scheduling algorithms

## Algorithms 

1) FCFS (First come first served)
2) SJF (Shortest Job First)
3) Priority Scheduling 
4) Round Robin
5) MLFQ (Multi level feedback queue)

## Tech Stack 

- C++17
- Object oriented Programming
- STL
- Data structures
- Operating systems

## Features 

- process management
- Gantt chart visulaization
- Scheduling metrics
- Algorithm Comparison
